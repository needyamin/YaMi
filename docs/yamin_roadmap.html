YaMi Rust Migration Roadmap

Gradually evolve YaMi from a Python/PyTorch-based LLM project into a hardware-independent Rust ML runtime.

View Roadmap

Project Goal

Rust Core

Build the core tensor and runtime engine in Rust.

CPU Backend

Provide an optimized native CPU execution backend.

Vulkan GPU

Support GPU compute without making CUDA mandatory.

Resource Control

Control CPU threads, RAM, GPU memory and execution.

Core Principle

Do not rewrite everything at once. Replace one layer at a time.

Every Rust component should be tested against the existing PyTorch implementation before moving to the next layer.

YaMi — Rust-based ML / LLM Runtime

Python for high-level APIs. Rust for the core. CPU and Vulkan first. CUDA optional.
