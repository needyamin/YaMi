* Consumer/development hardware
* Limited compute

## 28. Critical Requirement

The most important requirement is:

**Build small now, but architect for scale.**

Do not claim that a 16 GB RAM computer can train a GPT/Gemini-scale model.

Instead, make the codebase structurally capable of evolving toward larger systems.

The initial model should be intentionally small enough to experiment with locally.

The architecture should make it possible to replace:

* local storage → object storage
* single GPU → multi-GPU
* single node → multi-node
* ordinary checkpoint → sharded checkpoint
* simple DataLoader → distributed DataLoader
* local inference → model-serving cluster

without rewriting the entire project.
